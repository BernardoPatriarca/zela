# zela
Plataforma web de gestão financeira e prestação de contas para curatela e tutela. Registra receitas, despesas e comprovantes, concilia extratos OFX/CSV e gera o relatório no formato de cada comarca, com trilha de auditoria. TCC de Sistemas de Informação (UNIMATER). Java + Quarkus, Angular + PrimeNG, Supabase e AWS.
